# План портфолио: 50 работ

Цель по форматам: 10 лендингов, 14 корпоративных сайтов, 8 магазинов, 10 веб-приложений, 8 специальных проектов.
Каждая работа — отдельный адрес, реальные скриншоты, сценарий, QA и честный тип (клиент / собственный продукт / демо).
Демо-проекты живут в `kirill-dorkin/microstudio-showcase`, деплой `ms-<slug>.vercel.app`, `noindex`, видимая плашка «Демонстрационный проект».

Статус: ✅ опубликовано и проверено · 🔨 в работе · ⏳ запланировано · ⛔ заблокировано (не публикуется)

## Порядок работы
Партии по 5 демо: код → локальный QA → коммит → деплой → QA на проде → скриншоты с прода → Lighthouse → экспорт реестра → `pnpm sync:showcase` → тесты сайта → коммит и пуш.
