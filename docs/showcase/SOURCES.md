# Найденные исходники: отбор

Подход — см. `CHECKPOINT.md`: берём готовые сильные проекты с открытой лицензией и адаптируем минимально.
Скриншоты исходных интерфейсов (как они выглядели до наших изменений) — в `sources/<id>/original-*.jpg`.

Как отбирали: каталог бесплатных тем Astro (368 тем просмотрено по названию и описанию), поиск по GitHub по категориям, затем для ~20 кандидатов — живое демо в браузере на 1440 px и 390 px, вся страница целиком.

## Отклонено после просмотра

| Кандидат | Причина |
|---|---|
| Boutique (Sv3nskie/astro-theme-boutique) | Вместо фото — заглушки «HERO PHOTO», «PRODUCT»; без полной замены контента сайт пустой. |
| Northlight (Sv3nskie/astro-theme-northlight) | Секции закреплены и прокручиваются анимацией: при обычной прокрутке — длинные пустые экраны. Это перехват прокрутки. |
| Orrery (formgong/orrery-astro-theme) | Та же проблема: анимированные карточки на пустом фоне, текст низкого контраста. |
| Shoal (formgong/shoal-astro-theme) | Хорошее качество, но та же ниша, что Marby. Резерв для категории «недвижимость». |
| Astrorante, Astrogency (unfolding-io) | В репозитории нет явной лицензии (NOASSERTION) — нельзя гарантировать право на публикацию. |
| Horizon (Cosmic-Themes) | GPL-3.0 и SaaS-направленность; оставлено в резерве. |
| Said Yes! | AGPL-3.0, узкая ниша (свадьба). |
| Шаблоны из поиска GitHub по запросам «restaurant / hotel / real estate template» | Большинство — учебные проекты среднего уровня; под критерий «уже выглядит как работа студии» не прошли. |

## Резерв для следующих партий
Shoal (недвижимость), Lapse (SaaS), Noble Muse (магазин одежды того же автора, что Maison), Chalet, Quiet Bar, 3dinterior, Folex Lite, Mintaka — посмотреть так же, на двух ширинах, перед выбором.
