# 01. PRODUCT / BRAND / INFORMATION ARCHITECTURE

## 1. Продукт и позиционирование
**MicroStudio — студия разработки сайтов и цифровых решений для бизнеса.** Создаёт одностраничные сайты, корпоративные сайты, каталоги и интернет-магазины; помогает с UX/UI, языками, продвижением и поддержкой. Не позиционировать исключительно как «лендинги по 1500» и не представляться большой командой без данных.

**Ключевой оффер:** «Создаём сайты, которые работают на ваш бизнес».
**Пояснение:** «От небольшой страницы до интернет-магазина и индивидуального проекта. Продумываем дизайн, удобство и путь клиента к обращению».
**Основное действие:** «Обсудить проект». Вторичное: «Смотреть примеры».
**Целевые пользователи:** предприниматель с небольшим бюджетом, владелец растущего бизнеса, маркетолог/руководитель, заказчик сложного проекта.

## 2. Структура страниц (обязательно)
Маршруты App Router с i18n: `/{locale}` (`ru`, `en`), `/{locale}/services`, `/{locale}/services/websites`, `/design`, `/advertising`, `/support`, `/{locale}/work`, `/{locale}/work/[slug]`, `/{locale}/about`, `/{locale}/blog`, `/{locale}/blog/[slug]`, `/{locale}/special`, `/{locale}/contact`, `/{locale}/privacy`. 404 локализована, sitemap.xml, robots.txt, metadata, OG. `/` редирект на `/ru` (или edge locale detection с дефолтом RU; SEO каноникал без дублирования). Меню: «Услуги», «Проекты», «О студии», «Блог», CTA «Обсудить проект». В footer — политика, контакты, соцсеть и акция.

## 3. Главная — строгий порядок и роль
1. **Header** высота 70–76px desktop, 60–66px mobile. Существующий логотип, языки RU/EN, меню. Стеклянная подложка только умеренно, без случайных эффектов.
2. **Hero (первый экран)**: headline 2–3 строки, 1 короткое объяснение, CTA + secondary. Рядом/ниже — галерея из трёх реальных скриншотов OSS демо как кинематографичные layered cards. Над галереей компактная честная метка «Интерактивные open-source демо», никогда «Наши клиенты». На 390px текст виден целиком и CTA без застревания на сложной анимации. Можно ротацию с кнопками предыдущий/следующий, но не autoplay, если портит UX.
3. **Selected work**: ровно 4 карточки из seed в таком порядке: магазин, ресторан, фотограф, SaaS. Крупные desktop скриншоты; на hover лёгкий zoom <=1.025. Видимые названия и категории. Обязательно бейдж «Открытое демо» и ссылка на github в details.
4. **Сервисы**: 4 выразительные секции с заголовком, одной полезной мыслью и 2–4 пунктами возможностей, перейти на детальную страницу.
5. **«Как это работает»**: этапы «Обсуждаем задачу» → «Предлагаем структуру и дизайн» → «Разрабатываем и проверяем» → «Публикуем и при необходимости развиваем». Без обещанных сроков.
6. **Показ полезной механики**: короткий интерактивный пример пути клиента: открывает страницу → выбирает услугу → получает подготовленное сообщение → может написать. Это **демо**, не реальная отправка. На mobile не перекрывать элементами.
7. **Специальное предложение**: компактная секция с «Одностраничный сайт — 1 500 сом», отличать акцию от индивидуальной разработки. CTA `/ru/special`.
8. **О студии / принципы**: без фальшивых фото команды, странных абзацев и неподтверждённых цифр: «Делаем понятные сайты, а не просто красивые страницы», 3 принципа «Понятно клиенту», «Удобно с телефона», «Можно развивать дальше».
9. **FAQ**: первые 5 содержательных вопросов из data/faq. Ссылка на полную страницу услуги/контакты.
10. **Final CTA**: «Расскажите о проекте» + «Даже если пока есть только идея — обсудим, с чего начать». Реальное действие Instagram/WhatsApp по конфигу.

## 4. Work / портфолио
- Название страницы **«Проекты и примеры»**, не «Клиенты MicroStudio».
- Вводный дисклеймер дословно: «Пока здесь представлены открытые демонстрационные проекты и интерфейсы — чтобы вы могли посмотреть разные подходы к дизайну и функциональности. Это не клиентские кейсы MicroStudio. По мере появления собственных работ мы заменим примеры реальными проектами.»
- Категории: Все / Интернет-магазины / Сайты для бизнеса / Лендинги / Веб-приложения / Портфолио / Контентные сайты. Из seed 7 записей. Фильтр по category — рабочий клиентский, без перехода и скачков скролла, query URL сохраняется при перезагрузке (`?type=ecommerce`); на мобильном — горизонтальные pills со скроллом, aria-labelled.
- Каждая карточка: качественный настоящий скриншот, название, ниша, краткое резюме, `Open-source demo`, стрелка; click — подробная страница. Не выскакивает немотивированный внешний редирект.
- Каждая `work/[slug]`: hero screenshot + title, метка demo, источники GitHub/demo, описание, 3 фактически реализованные возможности из seed, ещё 2 скриншота реального интерфейса (desktop/mobile) при наличии, CTA «Нужен похожий сайт? Обсудим ваш проект». В конце credit: имя автора, ссылка на лицензию MIT, дисклеймер «Не разработано для заказчика MicroStudio».
- Структура карточек строится из data, замена demo на свой кейс требует поменять один content object. Для собственных кейсов отдельно поля client, year, goal, contribution, permission, result (только если подтверждены).

## 5. Services
`/services` — overview с четырьмя направлениями; 4 detail страницы — уникальные полноценные тексты. Каждая содержит: hero с оффером, кому подходит, что делаем, что получает заказчик, сценарий работы, relevant demo projects, FAQ 4–6 пунктов, final CTA. Не дублировать дословно одни и те же абзацы. Статьи/примеры использовать как переходы. Не указывать «фиксированная цена» кроме special.

## 6. Special / акция
Заголовок «Одностраничный сайт для бизнеса — 1 500 сом». Небольшой текст «Специальное предложение для тех, кому нужна компактная страница с услугами и контактами». В базовой версии по этому ТЗ: одна адаптивная страница, блок о бизнесе, основные услуги/товары, контакты и кнопка связи, базовые метаданные SEO, публикация по согласованному способу. Отдельно рассчитываются: домен, платный хостинг/сервисы, многоязычность, реклама, каталог с управлением товарами, интернет-магазин, онлайн-оплата, нестандартные интеграции, полноценные тексты/фото под заказ. Не обещать срок, количество правок, регистрацию домена, включённую поддержку и безлимитные изменения. Условия согласовываются до старта.

## 7. About
Не выдавать компанию за агентство из 20 человек и не вставлять стоковое фото команды с «основатели». Текст: «MicroStudio — студия, которая помогает бизнесу выстроить понятное присутствие в интернете. Мы уделяем внимание не только внешнему виду, но и тому, как человек находит нужную информацию и связывается с компанией». Раздел «Наш подход» четыре принципа, стек Next.js/React/TypeScript/HTML/CSS/аналитика **только при фактической применимости**, контакты и CTA. Не писать год основания и число клиентов без источников.

## 8. Contact
Интерактивный бриф 4 поля: тип проекта (обязательно), задача свободным текстом (необязательно), ориентир бюджета (опционально, «до 10 000 / 10–30 / 30–100 / от 100 тысяч / пока не знаю» с сомами и без требования ответа), способ связи (Instagram/WhatsApp — WhatsApp только если конфиг содержит реальный номер). Согласие на передачу сведений через выбранный мессенджер. UX: генерировать сообщение, явно показать preview текста, CTA «Скопировать и открыть Instagram»; если есть Whatsapp «Перейти в WhatsApp с сообщением»; после нажатия показывать «Текст скопирован» только при успешном copy. Не обещать автоматической доставки и не сохранять личные данные без цели.

## 9. Motion, typography, navigation
Токены: background `#0B0D0F`, elevated `#171A1D`, lime `#C7F66C`, text `#F6F7F3`, muted `#A2A8A6`, border `#2A2F2D`. Не вставлять CSS хаотично по страницам. Шрифты Manrope / Inter через next/font. Layout max-width 1280px, page gutters 20px mobile / 40px tablet / 64px desktop. 12-column desktop, 4-column mobile. H1 64–88px desktop (clamp), 36–44px mobile. Body 16–18px, line-height 1.45–1.6. Минимальный tap target 44px. Масштаб анимаций 250–500ms, `easeOut`, не запускать постоянные тяжелые WebGL/Canvas эффекты. Никаких экранов 100vh с обрезанием на iOS, использовать 100dvh и margin/padding для клавиатуры/безопасных зон.

## 10. Визуальные принципы
- На одном экране один главный смысл. Hero с фокусом на названии и демонстрации. Доказательства — реальные интерфейсы, а не «сфера в космосе».
- Большинство секций минималистичны, ритм задаёт крупная типографика, а карточки разных проектов не должны быть одинакового мелкого размера.
- Правильные разные ratio скриншотов; не искажать картинку (`object-fit: cover` с правильным object-position), светлые сайты показывать в собственной рамке с нейтральной тенью.
- Header после scroll слегка уплотняется, мобильный drawer доступен клавиатурой, Esc закрывает, focus возвращается на кнопку, body scroll блокируется.
- Ссылки на внешние demo/source — новая вкладка, rel="noopener noreferrer". Предусмотреть этикетку «Открыть живое демо».
