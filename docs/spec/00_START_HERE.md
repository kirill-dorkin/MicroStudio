# MICROSTUDIO — ПОЛНОЕ ТЗ / CLAUDE CODE

**Назначение:** создать и запустить полноценный сайт компании MicroStudio, а не макет, который потом потребуется наполнять. Язык основной — русский; второй — английский.

**Принцип:** сайт выходит с 7 проверенными open-source демо-проектами, заполненными услугами, FAQ, статьями и работающим способом связи. Не заполнять выдуманными отзывами, кейсами или контактами.

### Что читать по порядку
1. `CLAUDE_CODE_PROMPT.md` — рабочий промпт агента.
2. `docs/01_PRODUCT_AND_DESIGN.md` — цели, маршруты, дизайн, структура.
3. `docs/02_IMPLEMENTATION_AND_QA.md` — техническая реализация, SEO, безопасность, тесты, приёмка.
4. `docs/03_PORTFOLIO_AND_LICENSES.md` и `data/portfolio.seed.json` — **обязательные** реальные open-source примеры.
5. `docs/04_COPY_AND_CONTENT.md` + `data/` + `content/blog/` — тексты, структура и контент.
6. `docs/07_PRIVACY_RU_EN.md` — complete baseline legal information page copy (requires review before deployment if tracking is added).
7. `docs/05_DELIVERY_CHECKLIST.md` — чек-лист «можно публиковать».

### Чёткие решения по неизвестным данным
- Instagram компании предоставлен заказчиком: `https://www.instagram.com/microstudio_official/`.
- Номер WhatsApp, рабочая почта, домен и адрес **не предоставлены**. Не выдумывать. При отсутствии реальных данных CTA направлять на Instagram с корректной подписью «Связаться в Instagram»; добавить конфигурацию для подключения WhatsApp без переработки компонентов.
- Название и брендинг — **MicroStudio**. Существующий логотип в репозитории использовать прежде всего; если его нет, чистое текстовое написание `MicroStudio` (не генерировать вымышленный фирменный знак).
- Не придумывать юридическое лицо, годы основания, размер команды, сроки разработки, показатели конверсии и гарантии заявок.
- Акция за 1 500 сом — только компактный одностраничный сайт, отдельно от индивидуальных проектов и рекламы.
- В старом коде могут быть важные данные: сначала аудит, затем бережная работа. **Никаких удаления, переписывания истории и массовых правок без необходимости**.
